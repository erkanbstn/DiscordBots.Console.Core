# Discord Bots

Discord botlarını katmanlı bir konsol çözümünde çalıştırır.

## Ne var

Ortak tipler, veri erişimi ve bot projeleri ayrı klasörlerdedir. Bot jetonu geliştirme ayarlarındadır.

## Çalıştırma

Çözümdeki bot projesini başlangıç yapıp çalıştırın.

## Yığın

.NET 7, Discord.Net, Entity Framework Core ve SQL Server.
